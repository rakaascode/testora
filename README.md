## ✨ Kenapa Testtora?

Dunia aplikasi mobile berkembang cepat, tapi banyak developer indie dan tim kecil kesulitan mendapatkan **feedback nyata** sebelum rilis. Di sisi lain, banyak pengguna ingin mencoba aplikasi baru dan memberi masukan yang berarti — tapi tidak ada wadahnya.

**Testtora hadir untuk menjembatani itu.**

Kami membangun ruang komunitas tempat:

- 🔍 **Developer** bisa mem-publish aplikasi mereka untuk ditemukan & diuji
- 🧪 **Tester & reviewer** bisa mencoba aplikasi baru, memberi ulasan jujur, dan melaporkan bug
- 🤝 **Komunitas** tumbuh bersama lewat kolaborasi terbuka, transparan, dan gratis untuk semua

> Dibangun oleh komunitas, untuk komunitas. 100% open source. 🚀

## 🧩 Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 🔎 **Discovery** | Jelajahi aplikasi mobile baru dari berbagai kategori & tahap pengembangan |
| ⭐ **Review System** | Beri & baca ulasan dari tester nyata, bukan bot atau review palsu |
| 🧪 **Testing Hub** | Ikut program beta testing, laporkan bug, dan bantu developer memperbaiki produk |
| 📈 **Improvement Tracker** | Pantau progres perbaikan aplikasi berdasarkan feedback komunitas |
| 🏆 **Reputation & Badge** | Kontributor aktif mendapat badge dan reputasi di komunitas |

## 🛠️ Tech Stack

> *Sesuaikan bagian ini dengan stack yang benar-benar kamu pakai.*

- **Frontend:** React / Next.js
- **Backend:** Node.js (Express) / NestJS
- **Database:** PostgreSQL
- **Auth:** JWT / OAuth
- **Deployment:** Docker + CI/CD (GitHub Actions)

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/testtora/testtora.git
cd testtora

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env

# Jalankan project
npm run dev
```

Buka `http://localhost:3000` dan mulai eksplorasi 🎉

## 🤝 Cara Berkontribusi

Testtora tumbuh berkat kontributor seperti kamu! Ada banyak cara untuk terlibat:

1. 🍴 **Fork** repository ini
2. 🌱 Buat branch baru (`git checkout -b fitur/nama-fitur`)
3. 💻 Lakukan perubahan & commit (`git commit -m 'feat: tambah fitur X'`)
4. 📤 Push ke branch kamu (`git push origin fitur/nama-fitur`)
5. 🔁 Buka **Pull Request**

Baca [CONTRIBUTING.md](CONTRIBUTING.md) untuk panduan lengkap sebelum mulai.

Nggak bisa coding? Kamu tetap bisa bantu lewat:
- 🐞 Melaporkan bug
- 💡 Mengusulkan ide fitur
- 📝 Memperbaiki dokumentasi
- 🧪 Ikut jadi beta tester aplikasi di platform
